What each type is for

Data flow — Level 0 & 1

Tracks data in motion. Level 0 is the whole system as one bubble and fixes the scope; Level 1 opens it into the main processes and the stores they use.

Use case

States what the system does for each actor, as goals. Carries «include» for steps that always happen and «extend» for optional ones.

Class & ER

The structure. A class diagram gives attributes, methods, inheritance and composition; an ER diagram gives the same data as entities, attribute ellipses and relationship diamonds.

Sequence & activity

The behaviour. A sequence diagram shows messages between objects in order; an activity diagram shows the workflow with its decisions and loops.

State chart

The lifecycle of one object — every state it can be in and the event that moves it to the next one.

Component & deployment

The implementation view. Components show the software modules and what they depend on; deployment shows which hardware node each piece runs on.

Once you've downloaded it

Import into EdrawMax

File → Import → SVG, or drag the file onto the canvas. Every shape, arrow and label stays a separate editable object.

Arrowheads are safe

Arrowheads are drawn as real geometry, not SVG markers, because EdrawMax drops markers on import and the arrows would otherwise disappear.

Check it against the rules

Before submitting, run your diagram past the rules checklist — balancing, naming discipline and the no-direct-store-to-store rule are where marks are usually lost.
